Powered by **Gemini 2.5 Flash**, built with **React + TypeScript + FastAPI**.

- 🔁 Automatic key rotation across N API keys on rate limits, plus retries on network errors
- 💸 Lower API costs by skipping blank-canvas requests and compressing images to 768px
- 📊 Token usage tracked locally in the browser
