### Featured Project

#### 🧮 [AICalc — AI-Powered Visual Calculator](https://github.com/AK01177/AICalc)

A multi-platform web app that lets users draw math, physics, and chemistry problems on a canvas and get AI-solved results rendered in LaTeX. Powered by **Gemini 2.5 Flash**, built with **React + TypeScript + FastAPI**.

- Freehand drawing, movable text boxes, step-by-step explanations
- Auto-switches between N API keys on rate limit; retries on network errors
- Cuts API costs by skipping blank canvas requests and compressing images to 768px
- Tracks token usage locally in the browser

→ **[Live Demo](https://aicalc-frontend.vercel.app)** · **[Repo](https://github.com/AK01177/AICalc)**
